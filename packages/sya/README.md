# sya

Short alias for [`seeyourai`](https://www.npmjs.com/package/seeyourai) — See Your AI.

```bash
npx sya
```

This package installs the `sya` command, which is identical to `seeyourai`. Use whichever you prefer.

For documentation, issues, and source code, see the main package: [github.com/seeyourai/seeyourai](https://github.com/seeyourai/seeyourai)
